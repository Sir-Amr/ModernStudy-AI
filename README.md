# AI Study Companion - رفيق المذاكرة

تطبيق ويب تفاعلي لتحويل ملفات PDF إلى تجربة تعليمية ذكية باستخدام الذكاء الاصطناعي.

## المميزات
- رفع ملفات PDF واستخراج النصوص
- تلخيص تلقائي بالفصول
- توليد اختبارات وبطاقات تعلم
- مساعد محادثة ذكي (RAG)
- لوحة تحكم لمتابعة التقدم
- تحليل نقاط القوة والضعف

## التقنيات المستخدمة
- **Frontend**: React 18, Bootstrap 5, Framer Motion (motion)
- **التفاعل**: Recharts, Sonner (toasts)
- **الأدوات**: Vite, React Router 7
